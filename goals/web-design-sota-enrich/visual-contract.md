# Visual contract — web-design-sota-enrich

## Thesis
Definitive PE workspace: rich but **subtly quiet**. Atmosphere serves scan + paste, never competes.

## Surfaces (depth)

| Surface | Depth | Must feel |
| --- | --- | --- |
| Recipe detail | Deep | Fast fill → copy; sticky actions; hub **below** workspace if clustered |
| Pattern detail | Strong | Definition/template first; hub **after** primary content if clustered |
| Home / recipes index | Solid | Find a recipe in <10s |
| Sources / chrome | Light | Trustworthy, not redesign-for-show |

## Quiet richness allowed
- Soft elevation, refined borders, restrained hero wash
- Lane accents for taxonomy only
- Micro-motion for copy/theme/hub only; `prefers-reduced-motion: reduce` hard stop

## Forbidden
- Loud marketing gradients, decorative loops, 3D, charts
- Fake “AI sparkle” clutter on workspace
- Contrast failures on text/controls
